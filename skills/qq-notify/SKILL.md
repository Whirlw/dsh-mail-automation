# 用 QQ 机器人通知我

## 工具（首选）

`qq_notify`：

| 参数 | 说明 |
| --- | --- |
| `text` | 正文；长的自动分片 |
| `markdown` | 是否用 QQ Markdown（默认跟随插件配置，通常开） |

返回 `{ ok, sent, chunks }`；`ok=false` 时 `error` 说明原因（缺凭据 / 没 openid / 频控）。

兜底：只有**有 shell 的会话**才能用工作区里的 `qq-send.mjs`（`node qq-send.mjs "内容"`，支持 `--markdown`/`--dry-run`）。
邮件 agent 预设没有 shell，做不到这一点。发不出去就如实说明 `error`（频控可稍后重试一次），不要另找脚本、也不要谎称已发。

## 什么时候发

- 用户明确说「通知我」「发我 QQ」。
- 邮件判定为**紧急**：涉及钱、账号安全、考试/作业截止、面试/录用、签证、学校正式通知、罚款、服务中断，
  且需 24 小时内行动。
- 每日总览由插件自己发，不要重复发。

## 什么时候不发

- 普通知会、营销、订阅摘要。
- 同一封邮件已经发过（每封只发一次）。
- 用户没要求、也不紧急——主动消息会打扰人。

## 规矩

- ≤3 行，第一行说清是什么事；第一行用 `**🚨紧急｜<来源>**` 这类固定抬头。
- 不粘贴邮件全文、密码、验证码、完整链接。
- 频控：单关系 20 条/分钟、每天 1000 条；不要循环里狂发。

## QQ Markdown 边界

支持 `#`/`##`、`**加粗**`、`*斜体*`、`~~删除线~~`、`- ` 列表、`1. ` 列表、`> ` 引用、
`[文字](链接)`、表格、`---`；不支持代码块、行内反引号、HTML 标签、非公网图片。
Markdown 不被支持时插件会自动退回纯文本重发，但那时只剩符号——所以别写复杂排版。
